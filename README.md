# Simple Interest Calculator

A simple and easy-to-use **Simple Interest Calculator** that calculates the interest earned and the total amount based on the principal amount, interest rate, and time period.

## 📌 About the Project

The Simple Interest Calculator is a small web-based project designed to demonstrate how simple interest is calculated using a basic mathematical formula.

It is suitable for beginners who are learning:

* Basic mathematics and formulas
* HTML, CSS, and JavaScript
* User input handling
* Basic DOM manipulation
* Building simple web applications

## 🧮 Simple Interest Formula

Simple Interest is calculated using:

```text
SI = (P × R × T) / 100
```

Where:

* **P** = Principal Amount
* **R** = Rate of Interest per year
* **T** = Time Period in years
* **SI** = Simple Interest

The total amount is calculated as:

```text
Total Amount = Principal + Simple Interest
```

### Example

If:

```text
Principal = ₹10,000
Rate = 5%
Time = 2 years
```

Then:

```text
SI = (10,000 × 5 × 2) / 100
   = ₹1,000
```

Therefore:

```text
Total Amount = ₹10,000 + ₹1,000
             = ₹11,000
```

## 🚀 How to Use

1. Clone the repository:

```bash
git clone https://github.com/your-username/simple-interest-calculator.git
```

2. Open the project directory:

```bash
cd simple-interest-calculator
```

3. Open `index.html` in your web browser.

4. Enter:

   * Principal amount
   * Interest rate
   * Time period

5. Click the **Calculate** button.

6. The calculator will display the simple interest and total amount.

## 📊 Calculation

The calculator performs two calculations:

### Simple Interest

```text
(P × R × T) / 100
```

### Total Amount

```text
P + SI
```
